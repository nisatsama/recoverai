RecoverAI
AI-powered payment failure recovery system

## Problem

Failed payments cause merchants to lose recoverable revenue.

## Features

- Payment failure detection
- Failure reason analysis
- Recovery strategy selection
- Automated recovery actions
- Merchant dashboard

## Tech Stack

Frontend: React
Backend: Node.js / Express
Database: PostgreSQL
ORM: Prisma
AI: ...
Deployment: Docker

## Architecture

Client → API → Recovery Engine → PostgreSQL

## Installation

1. Clone repository
2. Install dependencies
3. Configure .env
4. Start PostgreSQL
5. Run Prisma migrations
6. Start server/client
